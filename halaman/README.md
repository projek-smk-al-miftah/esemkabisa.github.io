# 🔌 ALAT-ALAT ELEKTRONIK

### 💻 Website Informasi dan Penjualan Alat Elektronik

Selamat datang di repository **Alat-Alat Elektronik**! Website ini dibuat untuk memberikan informasi mengenai berbagai jenis perangkat elektronik, fungsi, manfaat, dan kegunaannya dalam kehidupan sehari-hari.

## 📌 Tentang Website

Website Alat-Alat Elektronik merupakan proyek berbasis web yang dibuat menggunakan HTML dan CSS. Website ini memiliki tampilan sederhana, modern, dan responsif sehingga dapat dibuka melalui komputer maupun HP.

- 🎧 **Audio dan Headset** — Perangkat untuk mendengarkan musik.

## 📂 Struktur File

Pastikan repository GitHub kamu memiliki struktur seperti berikut:

```text
alat-elektronik/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

**Keterangan:**
- `index.html` — Halaman utama website.
- `style.css` — Desain dan tampilan website.
- `script.js` — Fitur interaktif jika digunakan.
- `README.md` — Dokumentasi proyek.

Jika website kamu tidak menggunakan JavaScript, file `script.js` tidak wajib dibuat.

## 🚀 Cara Menjalankan Website

1. Buka repository GitHub kamu.
2. Pastikan file `index.html` dan `style.css` sudah tersedia.
3. Tambahkan file `README.md` ke repository.
4. Buka menu **Settings**.
5. Pilih **Pages**.
6. Pada bagian Build and deployment, pilih **Deploy from a branch**.
7. Pilih branch `main` dan folder `/ (root)`.
8. Klik **Save**.
9. Tunggu proses publikasi selesai.
10. Buka alamat website GitHub Pages yang ditampilkan.
